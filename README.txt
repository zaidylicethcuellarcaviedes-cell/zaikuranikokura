ZAIKURA - Sitio web de comida asiática
Abrir index.html con Live Server en Visual Studio Code.
Páginas: index.html, nosotros.html, productos.html, contacto.html
Estilos: style.css. Funciones y catálogo: script.js.
En script.js edita CONFIG para colocar WhatsApp, correo y redes reales.
Los precios, productos, imágenes y textos son demostrativos. Las imágenes requieren internet.
El formulario prepara un correo mediante mailto cuando se configura un destinatario; no envía datos a un servidor.
Modo oscuro y claro con preferencia guardada en el navegador.
